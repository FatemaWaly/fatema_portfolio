# Fatema Waly — Portfolio

Open `index.html` in any browser to view the site. Everything (HTML, CSS, JavaScript) is in that one file; fonts load from Google Fonts.

## Put it online with GitHub Pages
1. Create a public repo named `FatemaWaly.github.io` on github.com/FatemaWaly.
2. Upload `index.html` to it.
3. Repo Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute it is live at https://fatemawaly.github.io
